WHAT THE APP IS

Technikpool Scanner is a barcode inventory scanner for event equipment
(lighting, audio, staging). When a crew loads a truck, someone has to record
which cases went out and which came back; on paper it is not done at all, and
equipment goes missing. This app scans the label on a case as it is handled,
and the inventory updates on the spot.

WHO CAN USE IT

Anyone. Technikpool is free and open-source software, published under the MIT
licence at https://github.com/RuegerEvents/technikpool. Any person, band,
theatre group, school, church, camera club or company can download the server,
run it themselves, and use this app with it. There is no invitation, no
approval step, no waiting list, and no affiliation with us or anyone else
required. We do not operate a service anyone has to be a customer of, and we
cannot see or restrict who runs it.

The app also works with no server at all: "Explore the demo" on the first
screen runs a complete sample warehouse on the device — scanning, lookup and
inventory all work there, with no account, no sign-up and no network request.
That is a real feature of the shipped app, available to everyone who downloads
it.

Nothing is paid: no purchase, subscription, in-app purchase or paid tier, from
us or anyone else. The server software is free as well.

SETUP AND ACCESS TO THE MAIN FEATURES

Tap "Explore the demo" at the bottom of the first screen. No credentials are
needed and nothing leaves the device.

  * Scans — pick a location or production, then type an asset tag where it says
    "Manual entry". Tags run 40000001 to 40000014. The camera button works too:
    demo-tags.png next to this file (also attached to our reply of 1 Sep 2026)
    has QR codes for tags 40000001-40000004 to point it at.
  * Lookup — type the same tags to see an asset, where it is, and its history.
  * Inventory — lists every asset with its tag, so nothing has to be guessed.
  * Settings › Leave demo returns to the first screen.

To use the app for real, a person installs the open-source server (Docker
image, one command) and either scans the QR code on its Scanners page or signs
in with an email and password on that server.

Camera access is requested only for reading barcodes, and only when the scan
button is used; local-network access only when pairing with a server on the
same network. Both prompts follow the language of the interface.

ACCOUNTS

Accounts live on whichever server the user runs, not with us — there is no
Technikpool account and no central sign-up. Somebody running their own server
creates the first account on it during setup, and can create as many more as
they like. Pairing is either the QR code plus a short confirmation code in a
browser (RFC 8628 device authorization) or an email and password. Settings ›
Disconnect erases the stored token. Accounts are deleted in the web app on that
server; the app cannot create one, so it has none to delete.

There is no user-generated content and nothing is shared between users. The
only thing a user contributes is a scan of a barcode on their own equipment,
stored on their own server.

EXTERNAL SERVICES

None. The app talks to exactly one host: whichever Technikpool server its user
chose, which also handles authentication. No analytics, crash reporting,
advertising, payment or AI services of any kind. The app does not use the
advertising identifier and does not track. Demo mode makes no network request
at all.

OTHER

Same features and content in every region; the interface is German and English,
following the device language. Equipment rental is not a regulated industry,
and the app ships no third-party material.

TESTED ON
